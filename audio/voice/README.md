# Voices

There are no recorded voices yet. The game plays a boatswain's pipe and shows
the words on screen instead.

To add a voice, record the line and save it in this folder as `<id>.wav`,
`<id>.ogg` or `<id>.mp3`. The game looks for these ids and plays the file if
it finds one:

| id | When | Said by | Suggested words |
| --- | --- | --- | --- |
| `helm_port` | Course ordered to port | Quartermaster | "Port a point, aye!" |
| `helm_starboard` | Course ordered to starboard | Quartermaster | "Starboard a point, aye!" |
| `make_sail` | More sail ordered | Boatswain's mate | "Hands aloft! Make sail!" |
| `shorten_sail` | Less sail ordered | Boatswain's mate | "Hands aloft! Shorten sail!" |
| `lead_0` to `lead_20` | A sounding, in fathoms | Leadsman | "By the mark five!" / "By the deep six!" |
| `lead_no_bottom` | Too deep for the line | Leadsman | "No bottom with this line!" |
| `lead_too_fast` | Ship too fast to sound | Leadsman | "Too much way on her!" |
| `pale_water` | Shoal seen ahead | Lookout | "Pale water dead ahead!" |
| `aground` | She strikes | Quartermaster | "She strikes!" |
| `anchor` | Anchoring | Boatswain's mate | "Let go!" |
