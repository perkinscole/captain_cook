# Models

Models generated with Meshy from reference pictures. They are not used by the
game yet: everything in the game is still built in code.

| File | What it is |
| --- | --- |
| `seaman/seaman_rigged.glb` | A common seaman of the 1760s, textured, with a 24-bone skeleton. About 15,700 triangles. |
| `seaman/seaman_walking.glb`, `seaman_running.glb` | The same figure with a walking and a running clip. |
| `seaman/seaman_textured.glb` | The figure before rigging. |
| `gun/gun_4pdr.glb` | A 4-pounder ship's gun on its truck carriage, textured. About 400,000 triangles, which is heavy for a prop. |
| `meshy_output/` | Reference pictures and rendered previews from each step. |

The dress and the gun were described from memory of the period and have not
been checked against sources.
